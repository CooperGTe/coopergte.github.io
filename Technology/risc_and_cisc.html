what is instruction set architecture (ISA) in computer?
imagine it as language that the CPU talk
very specific code written in binary that cpu can decode and execute
cpu instruction example in human readable language:
```
load reg1 0001
# take a data from memory address 0001 and put it in register 1
load reg2 0002
# take a data from memory address 0002 and put it in register 2
add reg1 reg2 reg3
# add register 1 and 2 and put the result in register 3
```
